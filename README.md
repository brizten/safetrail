# TrailSafe

TrailSafe — MVP для планирования и контроля безопасности походов. В репозитории теперь есть две версии:

- `app.py` — исходный Python/Streamlit-прототип для быстрого тестирования идеи на компьютере.
- `mobile/` — мобильное приложение Expo/React Native для Android и iPhone.

## Что умеет MVP

- план похода с маршрутом, дистанцией, сложностью и контрольными точками;
- профиль безопасности: имя, телефон, группа крови, аллергии, болезни, опыт;
- оценка риска: низкий, средний, высокий, критический;
- тревожные условия: просрочка контрольной точки, позднее возвращение, долго нет связи, отклонение от маршрута;
- SOS-сообщение с координатами, маршрутом, последним контактом и медицинскими данными;
- ручной звонок `112` и ручная отправка SMS контактам;
- чек-листы для соло-кемпинга и экстренных ситуаций;
- локальное хранение данных.

## Важные ограничения

TrailSafe не заменяет спасательные службы, спутниковый маяк, профессиональную навигацию и подготовку к маршруту.

Приложение не звонит и не отправляет сообщения автоматически. Звонок, SMS и тревожное сообщение всегда требуют действия пользователя.

## Мобильная версия

Мобильное приложение находится в папке `mobile/`.

```powershell
cd mobile
npm install
npm run start
```

После запуска установите Expo Go на Android или iPhone и отсканируйте QR-код из терминала.

Подробные инструкции: [mobile/README.md](mobile/README.md).

## Streamlit-прототип

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Обычно Streamlit откроется на:

```text
http://localhost:8501
```

## Архитектура

Python-прототип:

- `app.py` — Streamlit-интерфейс;
- `database.py` — SQLite;
- `models.py` — dataclass-модели;
- `safety.py` — оценка риска и тревоги;
- `checklist.py` — чек-листы;
- `emergency.py` — SOS-сообщения;
- `config.py` — настройки.

Мобильное приложение:

- `mobile/App.tsx` — основной React Native UI;
- `mobile/src/types.ts` — типы маршрута, профиля, контактов и тревог;
- `mobile/src/logic/safety.ts` — оценка риска и тревоги;
- `mobile/src/logic/emergency.ts` — SOS-сообщения, `tel:` и `sms:`;
- `mobile/src/data/checklists.ts` — чек-листы;
- `mobile/src/data/defaults.ts` — стартовые тестовые данные;
- `mobile/src/storage.ts` — локальное хранение через AsyncStorage.
