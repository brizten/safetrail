# TrailSafe MVP

Python-приложение для планирования и контроля безопасности походов, особенно для соло-кемпинга, гор и леса.

## Архитектура

Приложение разделено на независимые модули:

- `app.py` — Streamlit-интерфейс: главная страница, создание похода, карта, чек-листы, риск, SOS, история и настройки.
- `database.py` — слой SQLite: профиль безопасности, контакты, походы, контрольные точки и инциденты.
- `models.py` — dataclass-модели: профиль, контакт, поход, контрольная точка и настройки тревоги.
- `safety.py` — оценка риска и проверка условий тревоги.
- `checklist.py` — чек-листы и инструкции для экстренных ситуаций.
- `emergency.py` — генерация SOS-сообщения, ссылок `tel:` и `sms:`.
- `config.py` — настройки приложения, путь к базе, предупреждения и константы.
- `requirements.txt` — зависимости.

SQLite хранит данные локально в `data/trailsafe.sqlite3`. В MVP нет облачной синхронизации, автоматической отправки SMS и автоматических звонков.

## Возможности MVP

- создание маршрута с точками старта и финиша;
- контрольные точки с плановым временем и координатами;
- профиль безопасности и экстренные контакты;
- настройка условий тревоги;
- ручное обновление последней связи и текущих координат;
- оценка риска: низкий, средний, высокий, критический;
- карта маршрута через Folium;
- SOS-режим с подготовкой сообщения, координатами, маршрутом и медицинскими данными;
- чек-листы для соло-кемпинга и экстренных ситуаций;
- история походов.

## Важные ограничения

Это приложение не заменяет спасательные службы, спутниковый маяк, профессиональную навигацию и подготовку к маршруту. Все тревожные действия требуют подтверждения пользователя. Приложение формирует сообщение и ссылки для звонка/SMS, но не отправляет их автоматически.

Личные данные и координаты сохраняются локально. Для реального использования включите шифрование диска, блокировку устройства и ограничьте доступ к файлу базы данных.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

После запуска откройте адрес, который покажет Streamlit, обычно:

```text
http://localhost:8501
```

## Быстрый сценарий проверки

1. Откройте «Настройки контактов» и заполните профиль.
2. Добавьте один экстренный контакт.
3. Откройте «Создание похода» и создайте маршрут.
4. Проверьте «Оценка риска».
5. В «История походов» отметьте выход на связь или контрольную точку.
6. В «SOS-режим» сформируйте тревожное сообщение и проверьте его содержание.

## Идеи для развития

- шифрование базы данных;
- реальная геолокация через мобильный клиент;
- интеграция со спутниковыми трекерами;
- экспорт маршрута в GPX;
- отправка уведомлений через подтверждённый SMS/e-mail-провайдер;
- роли доверенных контактов и общий доступ к маршруту;
- офлайн-режим для мобильного приложения.
